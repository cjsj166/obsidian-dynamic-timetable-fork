# 06 — 신규 기능

두 스케줄링 기능. 미착수 — 설계는 착수 시 구체화. **06은 05(제출) 이후로 미뤄도 무방**(YAGNI).

## 기능 1 — 끝나는 시각(마감)으로 태스크 지정

### 목적 / 왜
지금은 태스크 시간을 **시작시각 + 소요시간**으로 정한다. 하지만 "특정 시각까지 이 일을
끝내야 한다"처럼 **끝나는 시각(마감)으로 정의**하고 싶을 때가 있다. 걸리는 시간이 아니라
데드라인 기준으로 앵커링하는 대안 표기를 추가한다.

### 세부 계획 (초안)
- `src/core/document.ts` — 끝시각 표기를 파싱하는 새 time-spec 형태 추가(`@`/`;`와 공존).
- `src/core/projection.ts` — 끝시각에서 **역산**해 시작시각을 배치.
- `src/editor/*` — 인라인 칩/눈금 렌더 반영.

### 완료조건
- [ ] 끝시각 표기를 파싱하는 순수함수 + Jest 테스트 green
- [ ] projection이 끝시각 앵커 태스크를 역산 배치(경계/겹침 케이스 테스트 포함)
- [ ] 에디터에서 끝시각 태스크가 올바른 시각으로 렌더

## 기능 2 — 고정 스케줄을 "+N일" 오프셋으로 표시

### 목적 / 왜
고정/반복 스케줄을 그 날 기준 상대(예: "+1일 후")로 표시하고 싶다.

### 세부 계획 (초안)
- `src/core/projection.ts` 변경. 표시 형식·의미 설계가 더 필요.

### 완료조건
- [ ] 고정 스케줄이 "+N일" 오프셋으로 표시되는 규칙 확정 + 순수함수 테스트 green
