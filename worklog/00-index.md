## 실행 범위 (현재)

**이번엔 `01 → 02 → 03 → 04`까지만 실행한다.** 04(축 B)가 서버에서 완료된 뒤
05(축 A 제출)·06(신규기능)은 다시 의논해 결정한다.

전체 권장 순서는 `01 → 02 → 03 → 04 → 05`, **06은 05 이후 선택**(제출 후로 미뤄도 무방).
